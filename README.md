🤖 AI Voice Chatbot Assistant

An intelligent AI-powered desktop chatbot built with Python, featuring voice input, text-to-speech output, and LLM-powered conversations through the Groq API. The chatbot provides a seamless hands-free experience with a modern GUI built using CustomTkinter.

🚀 Features
🎤 Voice Recognition for user input
🔊 Text-to-Speech responses
🤖 AI-powered conversations using Groq LLMs
🖥️ Modern GUI built with CustomTkinter
⚡ Fast response generation
🛑 Speech interruption support
💬 Real-time conversational interface
🌙 Clean and user-friendly design
🛠️ Technologies Used
Python
CustomTkinter
SpeechRecognition
Pyttsx3
Groq API
Threading
Tkinter
